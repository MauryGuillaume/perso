Connexion au cabinet

Première connexion : active la double authentification.

  1. Installe une application d’authentification sur ton téléphone (Google Authenticator, Microsoft Authenticator, FreeOTP…).
  2. Ajoute un compte avec la clé ci-dessous (saisie manuelle, type « basé sur l’heure ») : ou touche ici depuis le téléphone
  3. Saisis le code à 6 chiffres qu’elle affiche.
